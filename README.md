# 🎮 Tic Tac Toe Game (Python)

This is a Human VS AI command-line based Tic Tac Toe game for two players, written in Python. It's a great beginner-level project to understand game logic, conditionals, and loops.

---

## 🚀 How to Run

1. Make sure Python is installed.
2. Open a terminal or Git Bash.
3. Run the script:

```bash
python Tic_Tac_Toe_Game.py
